# Pivot IA Quernel Intelligence — Plan d'implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Mettre en production le pivot IA : plateforme démo d'agents sur le VPS + site vitrine refondu (hero IA, pages /agents et /audit, endpoints PHP) + nettoyage serveur.

**Architecture:** Deux dépôts. (1) `agents-platform` : fork du template Next.js 16 rebrandé QI avec 6 agents orientés revenus, déployé sur le VPS 46.202.168.181 derrière Nginx sur agents.quernel-cloud.com, mode mock par défaut. (2) `site` : SPA React 19 + Vite existant, nouvelles routes /agents et /audit, endpoints PHP flat sur Hostinger mutualisé.

**Tech Stack:** Next.js 16 / React 19 / AI SDK + Claude (plateforme) · React 19 + Vite + react-router (SPA) · PHP 8.2 flat + SQLite + FPDF (API site) · Nginx + systemd (VPS) · Apache/.htaccess (Hostinger).
